# Railsware Senior QA (TradeZella) job posting

The reason this project exists. TradeZella is a trading-journal product; the role is senior QA with
emphasis on **manual/e2e testing, UX validation, requirements analysis, L3 root-cause investigation,
log analysis, HTTP/API understanding, Git, AI-assisted workflow, and real trading experience**.
Playwright (TypeScript) is the only named nice-to-have.

## Takeaways for the project
- QA artifacts must be the headline, not an afterthought → see [[qa-portfolio-alignment]].
- Trading correctness (balances, fees, P&L, order states) is the best place to show domain-aware testing.
- Build in observability (request IDs, JSON logs) so RCA write-ups can cite real log evidence.
- Use Playwright **TypeScript** specifically.
- Using GSD + LLM Wiki is itself evidence of "AI tools for workflow optimization".
