<objective>
Fix the root cause behind UAT gaps G-01-1, G-01-2 and G-01-3: `createHealthPoller` calls its timer functions as members of the `timers` object, which browsers reject with `TypeError: Illegal invocation`. The throw happens right after the ok update, the error handler turns it into "API unreachable", and no poll is ever scheduled. Add regression tests that apply the browser receiver rule inside Node/Vitest, so this class of bug fails in CI. Also stop programming errors from being shown as "API unreachable".

Purpose: Phase 1 success criterion 1 ("the web page shows API health status") is false in a real browser today. This plan makes the badge correct and keeps the 60s visible-only poll (D-02) working.

Output: fixed `web/src/lib/healthPoller.ts` and `web/src/lib/api.ts`, plus new tests in `healthPoller.test.ts` and `api.test.ts`. Each new test fails on the pre-fix code (RED commit) and passes after the fix.
</objective>
