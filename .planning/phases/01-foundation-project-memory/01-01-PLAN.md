Output: npm-workspaces monorepo (`api/`, `web/`), `GET /health` with DB-backed upstream cache (D-03, D-04, D-05), request-ID JSON logging (D-06, D-07, D-08 outbound line), a minimal web footer badge (D-01, D-02 on-load read), committed Drizzle migration applied to the dev database ([BLOCKING] schema push), and `npm run smoke`.
