## Usage Notes

- One file per feature, stored at `qa/test-cases/<FEATURE>.md`.
- IDs follow `TC-AREA-NNN` (e.g. `TC-MKT-001`) and are never reused, even if a test case is retired.
- Priority is P1, P2, or P3 (see `qa/TEST-PLAN.md` Priority section).
- Type is exactly one of: `positive`, `negative`, `boundary`, `security`, `UX`.
- For multi-step cases, separate steps inside the Steps cell with `<br>` (HTML line-break) tags so the table stays one row per test case.

## Notes on the endpoints under test

`GET /api/markets` (public, no session — D-44) returns `{ pairs: MarketPair[], fetchedAt, stale }`,
where each pair carries `id, symbol, name, pair, price, change24hPct, volume24h, marketCap`.
`GET /api/markets/:id/chart?window=1d|7d|30d` (public) returns
`{ id, window, points: { time, value }[], fetchedAt, stale }`. Both surface the shared D-09 error
envelope on failure — `404 UNKNOWN_MARKET` ("Unknown market") for a chart request outside the
curated list, `502 UPSTREAM_UNAVAILABLE` ("Market data is temporarily unavailable") when nothing
is cached and the upstream fails. Fixed user-facing strings this file asserts verbatim: the stale
banner's `Prices delayed`; the no-match line `No markets match "<query>".`; the unknown-market
line `This pair is not tradable here.`; and the quote-convention sentence `Prices are CoinGecko's
USD reference prices. This exchange treats USDT as 1:1 with USD.` The curated top-20 list (D-36)
is fetched dynamically from CoinGecko and changes over time — **no case in this file hardcodes
which coins are in it**; each case pins whatever the list currently holds when it runs, or pins
`scripts/smoke-dev.mjs`'s own stub fixture (`bitcoin`, `ethereum`, `tether`, `microcoin`, plus 21
filler coins) when run against the stub. Later phases' cases inherit this same rule. Automated
analogs already exist in `api/src/lib/marketData.test.ts`, `api/src/routes/markets.test.ts`,
`web/src/lib/format.test.ts`, `web/src/lib/marketsTable.test.ts`, `web/src/lib/marketsPoller.test.ts`,
`web/src/lib/poller.test.ts`, `web/src/lib/priceChart.test.ts`, `web/src/pages/Markets.test.tsx`,
`web/src/pages/Trade.test.tsx`, `web/src/components/StaleBanner.test.tsx`, and
`scripts/smoke-dev.mjs` sections (r)-(v) — cited per case below so the run report can point at
that automated proof as corroborating evidence rather than re-deriving it from a fresh manual
pass alone.
